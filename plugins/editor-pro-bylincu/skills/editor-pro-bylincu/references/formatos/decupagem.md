# Formato: decupagem (só montar os takes)

**Quando:** o pedido é "monta os takes", "corta os erros e os silêncios", "deixa limpo", sem pedir motion. Também serve para depoimento, entrevista e aula, ou quando o cliente vai editar o resto.

**Caminho:** `novo --formato decupagem` → decupagem → `voz` → `roteiro` → revisar legenda → `montar` → `final` (sem prévia obrigatória)

## Onde você trabalha
1. **Decupagem:** a melhor versão de cada frase, na ordem. Esse é o trabalho principal: capriche.
2. **Revisar legenda:** corrija nomes e marcas no campo `legenda` do roteiro. Se o cliente não usa legenda, deixe `"legenda": []`.

## O que não fazer
- Sem lettering, b-roll ou SFX automáticos. O punch-in continua, porque esconde o pulo dos cortes.
- Não alongue: o valor aqui é o vídeo limpo e direto.
