# comercial (anúncio, oferta, lançamento com pessoa)

**Etapas:** como talking-head, com uma camada de venda.

- **Estrutura (15–45 s):** gancho (0–2 s, a dor ou o benefício) → problema e solução (fala + b-roll do produto) → prova (número, resultado, depoimento) → oferta (card, legível por ≥ 2 s) → CTA nos últimos 3–4 s + fecho com a logo.
- **Nunca inventar** preço, condição ou prazo: só o que está no pedido ou no material do cliente.
- Peças: `Card` para a oferta, `Contador` para a prova numérica, `Pilula` para benefícios curtos. Trilha animada conforme o público (mostrar opções).
- Complementos que costumam combinar: `pixel2motion` (logo do fecho), `effects` (destaque sobre a pessoa).
